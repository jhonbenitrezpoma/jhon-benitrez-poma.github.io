# Ejercicios de Estructuras de Datos en Java

Proyecto desarrollado en **Apache NetBeans** que abarca la implementación de métodos para la manipulación de arreglos numéricos y un sistema de gestión de notas con validaciones.

---

## 📌 Contenido del Proyecto

### 1. Actividad 1: Gestión de Arreglos (`GestionArreglos.java`)
Contiene métodos desarrollados para realizar operaciones avanzadas sobre arreglos enteros:
* **Eliminar elemento:** Elimina la primera ocurrencia de un valor $x$.
* **Modificar elemento:** Reemplaza un valor $x$ por un nuevo valor.
* **Insertar en posición:** Desplaza elementos e inserta $x$ en el índice $y$.
* **Suma total:** Calcula la suma de todos los elementos almacenados.
* **Estadísticas:** Determina el valor menor, el valor mayor y el promedio.
* **Suma de impares:** Suma únicamente los números impares del arreglo.
* **Mover primer elemento al final:** Desplaza el elemento del índice 0 a la última posición.
* **Mover primer par al final:** Busca el primer número par y lo mueve a la última posición.

---

### 2. Actividad 2: Gestión de Notas (`NotasAlumno.java`)
Sistema para el cálculo de notas de un estudiante:
* Validaciones de entrada (mínimo 2 prácticas y notas dentro del rango 0-20).
* Identificación y eliminación de la práctica con la nota más baja.
* Cálculo del promedio exacto y redondeado.
